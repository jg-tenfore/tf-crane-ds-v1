The review panel jumps to any page and switches the width (1440, 1024, 768, 390), light or dark, and Tabs or Sidebar shop navigation, or opens the site full-window. Every page is a deep link (for example <Code>#/shop/golf-balls/dozens</Code>) and browser Back works.
